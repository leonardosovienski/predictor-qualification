## Observação

A API retorna `immutable=false`. A imutabilidade nativa de releases do GitHub é uma configuração do
repositório, que fica a critério do dono. Aqui a imutabilidade é procedimental: asset nunca é
sobrescrito, e versão nova sempre recebe tag nova (HF-002).
