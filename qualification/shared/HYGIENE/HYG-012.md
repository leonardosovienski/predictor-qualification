# HYG-012 — raízes de runtime no Windows (D-3) e VM Linux sob demanda (D-9)

**Critério:** diretórios criados; script testado uma vez; nenhuma escrita em instalação operacional.

**Resultado:** cumprido.

operacional (`C:\CAIN`, `C:\Cripto\operacao`, `C:\Cripto\pesquisa-*`, `C:\Cripto\restaurado-*`,
`C:\STOCKS\data`).

| Missão | Raiz | Estado |

| `crypto` | `C:\Cripto\qualificacao\runtime\` | já existia (vazia) |
| `brasileirao` | `C:\QUALIFICACAO\runtime\brasileirao\` | já existia (vazia) |
| `integration` (CAIN, Brasileirão) | `C:\QUALIFICACAO\runtime\integration\` | já existia (vazia) |
| `integration` (Cripto) | `C:\Cripto\qualificacao\runtime\integration\` | **criada** |
| `stocks` | nenhuma (D-1) | — |

A segunda execução confirma a idempotência (tudo `EXISTS`). Log: `RAW_LOGS/HYG-012_windows_runtime_roots.log`.

## Linux (D-9)

`scripts/provision_linux_vm.sh [raiz] [ref]` prepara um Ubuntu x86_64 descartável (VM na nuvem,
Codespaces ou runner do GitHub Actions):

- uv 0.12.18 baixado da release oficial e conferido por sha256
  (`89eadd7c76fc063887959510d5ba0ab1264dfd5f1143b925ddb73021a40acf16`), com Python 3.13 gerenciado
  pelo uv, cache e intérpretes dentro da raiz;
- clones limpos dos 7 repositórios públicos no `ref` pedido, sem credenciais;
- `PROVISION_RECEIPT.json` com SO, kernel, uv, Python e o HEAD de cada repo, sem segredos.

O host é destruído ao fim do uso. Nada ali é instalação operacional.

**Teste:** workflow `.github/workflows/provision-linux.yml` num `ubuntu-latest` limpo, com duas
execuções seguidas (provisionamento + idempotência).
[Run 35822087078](https://github.com/leonardosovienski/predictor-qualification/actions/runs/35822087078)
no commit `b5178b8e`, conclusão `success`: Ubuntu 24.04.5 LTS, kernel 6.17.0-1022-azure, uv 0.12.18,
CPython 3.13.15, `PROVISION_OK` nas duas execuções.

Observação: com `3.13` o uv instala o patch mais novo (3.13.15 no Linux; 3.13.14 no Windows local).
Se o baseline exigir o mesmo patch nos dois ambientes, ele passa a ser fixado no script.

Log: `RAW_LOGS/HYG-012_provision_linux_run35822087078.log`.
